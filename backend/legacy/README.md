# Legacy (unwired) campaign modules

`senders.py`, `campaigns.py`, `queue_worker.py`, `scheduling.py`, `templating.py`, and `automation_store.py` in this directory are an earlier campaign implementation that the running application never imports — the live stack is `backend/app.py` → `backend/outreach.py`, with pacing in `outreach._next_send_time`, sender/DNS rules in `outreach._clean_sender`, and persistence in `backend/database.py`. They were kept only because they existed as untracked files (no git history to recover them from) and they use a different model that was never wired into the FastAPI routes: `automation_store` job rows with `FOR UPDATE SKIP LOCKED`, `delay_min_seconds`, and per-sender OAuth refresh fields. Their relative imports point at the parent `backend` package (`from .. import config`) so they still resolve, but nothing else in the app references them. Do not add features here or import them from `app.py`; port anything still wanted into `outreach.py` deliberately, or delete this directory once that decision is made.
